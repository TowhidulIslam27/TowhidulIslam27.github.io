# Project screenshots

Drop screenshots/images for each project here as `.jpg` (or `.png`, just update the extension in
`src/data/content.js`). The filenames expected right now:

- `bangis-pro-1.jpg`, `bangis-pro-2.jpg`, `bangis-pro-3.jpg`
- `gridemy-lms-1.jpg`, `gridemy-lms-2.jpg`

Missing images are skipped automatically — no broken-image icons — so it's safe to add these
gradually. Add more entries to a project's `images` array in `content.js` as you go.
