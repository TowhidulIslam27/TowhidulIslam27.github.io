# Demo videos

Drop your software demo clips in this folder as `.mp4` files (optionally with a `.jpg` poster
frame). The filenames the site expects are set in `src/data/content.js` under each project's
`video` field — for example:

- `bangis-pro-demo.mp4` / `bangis-pro-poster.jpg`
- `gridemy-lms-demo.mp4` / `gridemy-lms-poster.jpg`

If a video file isn't present yet, the project card falls back to a "Demo video coming soon"
placeholder automatically — so it's safe to build/deploy before you've recorded everything.

Keep clips short (30–90s) and compressed (H.264 mp4, under ~15MB) so the site stays fast to load.
